# Exercism

My solutions to [Exercism](https://exercism.org/) coding exercises across language tracks.

## About The Project

Exercism is a platform for solving coding exercises and getting mentored to develop fluency in programming languages. This repository gathers my solutions, organized by track under `solutions/`: Bash, C#, Dart, Go, Java, JavaScript, Kotlin, PHP, Python, Ruby, Rust and TypeScript.
